# 🌐 Global E-commerce Sales Dashboard

## 📊 Project Overview

The **Global E-commerce Sales Dashboard** is an interactive business intelligence dashboard developed using **Microsoft Power BI**.

The dashboard analyzes e-commerce sales data to provide insights into **sales, profit, orders, products, and regional performance**.

The project is designed to help businesses understand their sales performance and identify important trends through interactive visualizations.


## 🎯 Business Objective

The main objective of this project is to transform raw e-commerce data into meaningful and interactive business insights.

The dashboard helps answer questions such as:

* What are the overall sales and profit?
* How are sales changing over time?
* Which regions generate the most sales?
* Which products or categories perform well?
* Which areas require further analysis?
* How does profit vary across different regions and products?


## 🛠️ Tools & Technologies

* **Microsoft Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated analysis
* **Microsoft Excel** – Data source and data preparation

## 📌 Dashboard Features

### 1. Executive Overview

Provides a high-level view of e-commerce performance using key performance indicators such as:

* Total Sales
* Total Profit
* Total Orders
* Sales Trends
* Regional Performance

### 2. Sales Analysis

Analyzes sales performance over time and provides insights into sales trends and business performance.

### 3. Regional Analysis

Provides a geographical view of sales and profit performance across different regions and locations.

### 4. Product Analysis

Analyzes product and category performance to identify products contributing to sales and profit.

### 5. Interactive Analysis

The dashboard includes interactive features such as:

* Slicers
* Filters
* Drill-down
* Hierarchies
* Interactive visualizations
* Page navigation

## 📈 Key Insights

The dashboard can be used to identify:

* Overall sales and profit performance
* Sales trends over time
* Regional differences in sales
* Product and category performance
* Areas with relatively lower sales or profitability
* Patterns that may require further business investigation

> The specific insights depend on the values and filters selected in the dashboard.

## 🔄 Data Preparation

The data was prepared using **Power Query** before visualization.

The preparation process included:

1. Loading the source data
2. Checking data types
3. Handling missing or inconsistent values
4. Cleaning the data
5. Transforming required columns
6. Creating the required relationships
7. Loading the prepared data into Power BI

## 🧮 Data Analysis

DAX measures were used to calculate important business metrics such as:

* Total Sales
* Total Profit
* Total Orders
* Other dashboard-specific KPIs

These measures were then used across different Power BI visuals.
